Oasis Infobyte Python Programming Internship

About This Repository

This repository contains the projects I completed as part of the Python Programming Internship at Oasis Infobyte. These projects helped me strengthen my Python programming skills, problem-solving abilities, and understanding of practical application development.

Projects

1. BMI Calculator

Folder: "python-Beginner-BMI-Calculator"

A Python program that calculates Body Mass Index (BMI) using a person's weight and height.

Features:

- Calculates BMI based on weight and height.
- Displays the BMI category.
- Handles invalid inputs and non-positive values.

Technologies: Python

"View Project" (./python-Beginner-BMI-Calculator/)

2. Random Password Generator

Folder: "python-Beginner-Password-Generator"

A Python program that generates random passwords based on the selected length and character types.

Features:

- Generates random passwords.
- Supports uppercase letters, lowercase letters, numbers, and symbols.
- Validates password length and character-type selections.

Technologies: Python, "random", "string"

"View Project" (./python-Beginner-Password-Generator/)

3. Chat Application

Folder: "python-Beginner-Chat-Application"

A real-time chat application that allows multiple clients to communicate through a server using Python socket programming.

Features:

- Real-time messaging between connected clients.
- Timestamps for messages.
- User connection and disconnection notifications.
- Supports multiple clients using threading.

Technologies: Python, "socket", "threading", "datetime"

"View Project" (./python-Beginner-Chat-Application/)
