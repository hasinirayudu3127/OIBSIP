# Random Password Generator

## Internship
Oasis Infobyte – Python Programming Internship

## Task
Task 3 – Random Password Generator

## Objective
The objective of this project is to build a Python tool that generates strong, random passwords based on user-defined criteria.

## Technologies Used
- Python
- random module
- string module

## Features
- Accepts a password length from the user.
- Enforces a minimum password length of 8 characters.
- Allows the user to select:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Symbols
- Requires at least 2 character types.
- Generates and displays a random password.
- Allows the user to generate another password without restarting the program.
- Handles invalid input with helpful error messages.
